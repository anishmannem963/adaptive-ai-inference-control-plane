# Retained evidence

This directory preserves compact, reviewable summaries of completed experiments. Every summary
identifies the exact source commit, GitHub Actions run, artifact, workload configuration, and
claim boundary.

The full Iteration 9 JSON artifact contains every individual run and scenario. GitHub retains
that artifact for 30 days; the summary remains in version control permanently. Re-run the
`Evaluation evidence` workflow to reproduce the full raw reports.

Do not describe controlled mock-provider costs as cloud savings or controlled fault timings as
public-provider failover latency. Real Cloud Run and AWS Bedrock results belong in a separate
evidence file after the explicitly authorized minimal-paid experiment.
